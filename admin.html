Lamby 老師後台尚未發布

⚙️ GitHub 連線設定（第一次使用請先設定）
怎麼取得發布金鑰？
  1. 登入 GitHub，打開 建立 Fine-grained token
  2. Token name 輸入 Lamby 後台；Expiration 選一個期限（例如 1 年）
  3. Repository access 選 Only select repositories，選 AR_game
  4. Permissions → Repository permissions → Contents 改成 Read and write
  5. 按最下面 Generate token，複製 github_pat_ 開頭的文字，貼到上面的欄位
這把金鑰只能修改 AR_game 這個 repository，不能動你帳號的其他東西。請不要分享給學生。
💡 小提醒：題號固定不變，刪除題目不會影響其他題的 QR Code。 新增題目後，按上方「🖨 列印 QR Code」印出新題目的 QR Code。 按「發布到網站」後，約 1 分鐘學生端就會更新。
